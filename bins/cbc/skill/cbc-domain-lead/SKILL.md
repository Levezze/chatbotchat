# Retired domain layer

The current hierarchy has Primarchs and implementation-owning Chapter Masters.
Read ../cbc-hierarchy/SKILL.md. Do not create another coordinating layer or new Captains.

For a fresh implementation assignment, use ../cbc-feature-lead/SKILL.md.
For an existing domain session, preserve its recorded identity and actual responsibilities.
Keep independently owned work moving; do not automatically seize its live children's branches
or restart them. Give the Primarch one concise inventory of current implementation owners so
it can coordinate them directly. Keep unresolved questions and actual holds visible.
Historical role metadata does not require continued domain relays or permission ceremonies.
