# Refresh to the simplified hierarchy

Protocol 3 supersedes the five-tier instructions. Operational roles are Primarch and Chapter
Master. The future dashboard Emperor is outside reporting and dormant today. Chapter Masters implement and spawn native subagents;
Primarchs coordinate parallel work, dependencies, resources and merge/release sequencing.

Reload the current shared skill and the responsibility being performed in the same session.
Preserve identity, active branch/worktree, real child handles, current work, decisions, rooms
and explicit holds. Existing Captains can finish their owned implementation directly under the
Primarch. Historical domain sessions supply one concise ownership inventory, not another relay
layer. Do not seize a live writer's work or restart all agents.

The refresh helper adds current fields/version without resetting records or transferring work:
`python3 <hierarchy-skill-dir>/scripts/refresh.py --state-dir <own-dir> --role <recorded-role>`.
Old metadata may remain for recovery; it does not reinstate retired instructions.
New Chapter Masters use canonical cbc-feature-lead. Legacy cbc-captain is an alias for the same role.

A refresh is not a native restart, automatic permission fix or reparenting transaction.
No mass stop, handoff ceremony, new Emperor, server queue or acknowledgement round is required.
Keep assigned independent work moving. Resolve any real ambiguous ownership through the Primarch
without blocking disjoint implementation.
